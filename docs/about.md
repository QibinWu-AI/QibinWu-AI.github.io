# 关于本站

本站用于记录和分享大语言模型（LLM）前沿论文的解析与技术笔记。

## 内容原则

- **通俗易懂**：用类比和直觉解释技术，而非堆砌公式
- **忠实原文**：先按论文原意实现，再讨论优化和偏差
- **工程视角**：不只关注算法本身，也关注部署、成本和实际效果

## 内容来源

论文解析基于对原始论文的阅读，参考社区讨论和技术博客，力求准确。如有错误，欢迎在 [GitHub](https://github.com/QibinWu-AI) 上反馈。

## 覆盖领域

- Transformer 架构创新
- 训练与微调技术
- 推理加速与优化
- 视觉语言模型
- 开源模型复现
